# CardMatchingGame（实验四基线）

Android 翻牌配对游戏，实验四版本：GridLayout + Button 显示 24 张牌，两张相同图案配对。

## 打开方式

用 Android Studio（Hedgehog 及以上）打开本目录，等待 Gradle Sync 完成后运行 `app` 模块。
若提示缺少 Gradle Wrapper，Android Studio 会自动补齐；也可在终端执行 `gradle wrapper` 生成。

## 分支说明

- `Main`：实验四基线版本（本文件所在分支）
- `Dev`：实验五 RecyclerView 改进版本

## 技术参数

- AGP 8.5.2 / Gradle 8.7 / compileSdk 35 / minSdk 26 / Java 17
- 依赖：AppCompat、Material Components、RecyclerView
